- 構図: 左下に匿名のノートPCと小さなマイク。そこから柔らかい波形が伸び、中央で数枚の無地メモカードに変わる。右側は明るい机面の余白。
- 色: オフホワイト、薄いグレー、淡いミント、柔らかいコーラル、少しだけ青。
- モチーフ: 録音ボタン、波形、短い抽象線のメモ、机上の小さな影。
- 文字の扱い: 画像内には文字なし。書き起こしは読めない短線だけ。

### 案2: ローカルから軽い入口へ

- 狙い: ローカル完結にこだわったが、精度と速度でつまずき、APIに任せることで日常に近づいた判断を表す。
- 構図: 左にノートPCの暗めの小窓、中央に重さを感じる処理バー風の抽象ブロック、右に軽く整ったメモカード。細い線で処理が流れる。右上にタイトル余白。
- 色: 暖かい机の木色、青灰、白、淡い緑、控えめな黄色。
- モチーフ: ノートPC、処理バー、音声波形、外部処理を思わせる小さな抽象ノード、メモカード。
- 文字の扱い: コード、モデル名、API名は入れない。端末風の線も読めない形にする。
- 参照元から離すための注意: OpenAI/Groq/Whisperのブランドやドキュメント画面を再現しない。クラウド図解にも寄せすぎない。

### 案3: AIで遊んで作った小さな道具

- 狙い: AIに全部任せるのではなく、試して、削って、自分用の道具にしていく手触りを出す。

- モチーフ: 付箋、録音ボタン、波形、小さなピクセルブロック、削られた機能を示す薄いカードの重なり。
- 文字の扱い: 付箋やメモに読める文字は入れない。
