## 共通パターンまとめ

- 構図: 提案: 左側40〜45%を静かなタイトル余白にし、右側へ生活ノート、無地の紙片、細い連続線を低密度でまとめる。
- 色: 提案: 紙の白、薄い木、淡い青緑、柔らかな黄色、青灰を中心にし、強い警告色を使わない。
- タイポグラフィ: 提案: 画像内には読める文字や数字を一切入れず、タイトルは画像外で重ねられる余白だけを設計する。
- モチーフ: 提案: 窓光、生活ノート、無地の紙片、折り目、細い線、淡いタイル、遠い都市の輪郭を抽象的に使う。
- 情報密度: 提案: 小さいOGP表示でも判別できるよう、主要モチーフを3〜4個に絞り、大きなグラフや図表を置かない。
- 余白: 提案: 浅い奥行きと広い空白を保ち、支え合いの流れを静かに考えられる呼吸を作る。
- 記事ヘッダーに使いやすい要素: 提案: 三期間を暗示する色温度の変化、一本の紙帯、緩くつながる三枚の無地紙片。
- 使わない要素: 提案: 実在ブランド、媒体、店舗、人物、ロゴ、国旗、観光名所、実在UI、固有レイアウト、報道写真、金融チャート、警告表示、読める文字や数字を使わない。

## Safety Review

- 参照元をコピーしていない: pass — 入力から一般化した線、紙、余白、色温度だけを使い、文章、画像、UI、固有レイアウトを転写していない。
- 抽象パターンのみ利用している: pass — 構図、質感、情報密度、色、余白として抽象化している。
- スクショ原本をGit管理していない: pass — スクリーンショット、参照画像、画像ファイル、画像URLを保存または埋め込んでいない。
- ロゴ、人物写真、独自UI、独自イラストを真似していない: pass — 3案すべてで実在物の再現を禁止し、無地の生活モチーフだけを提案している。
- 認証情報、個人用設定値、MCP接続設定の実体を書いていない: pass — 該当情報を含めていない。

### マレーシア暮らし記事向けの新方向性

#### Magazine Life Opening

- 狙い: 提案: NTAの世代間フローを、マレーシアの暮らしの中で統計を静かに読む導入場面として見せる。

- 向くテーマ: 提案: 制度や統計を日常から読み、家族や世代のつながりを考える記事に向ける。
- 注意: 提案: 実在誌面、記事カード、ロゴ、読める見出しや数字、政府資料の図表を作らない。

- 狙い: 提案: 支える時期と支えられる時期を、無地の生活メモが緩やかにつながる様子として見せる。
