## 共通パターンまとめ

- 構図: 観察: 記事は、普段の通勤経路から少し外れた経験を起点にしている。提案: 横長画面の左下に細い移動線と無地のメモ片を置き、線が一度だけ静かに分岐する。右側はタイトル安全領域にする。
- 色: 観察: 記事本文に色の指定はないため要確認。提案: 駅の白灰、くすんだ青緑、薄い黄、窓光の淡い青を少数使う。実在交通ブランドの色は避ける。
- タイポグラフィ: 提案: 画像内に読める文字、運賃額、通貨、駅名、日付を入れない。タイトルは画像外から重ねる前提で余白を取る。
- モチーフ: 観察: 記事の中心には、普段の経路、少し外れた駅、表示額への違和感がある。提案: 細い線、無地カード、半透明の区画、窓枠の影だけで示す。
- 情報密度: 提案: 運賃制度の説明図にせず、3〜4個の静かなモチーフに絞る。
- 余白: 提案: 右側または上部に広い余白を置き、壁、窓、机の明るい面として自然に見せる。
- 記事ヘッダーに使いやすい要素: 提案: 小さな差、慣れた経路からの寄り道、見えない区切り、日常の数字を見直す瞬間。
- 使わない要素: 実在の鉄道路線、駅名、運賃表、計算式、改札・車両の写真、ブランドロゴ、アプリや券売機のUI、読める文字と数字。
